# Frontend

**Audience: developers and Claude.**

Where a template from the [experience-library](../experience-library/) becomes a
configured, product-specific, production-grade frontend — the last code stage of the
pipeline before designer review and developer integration.

- [configured-experiences/](configured-experiences/) — per-product instances configured
  from experience-library templates
- [shared/](shared/) — cross-product shared frontend code (utilities, wrappers) that
  isn't part of the design system or owned by a single template

## Frontend code

This entire folder is executable frontend code.
