# Product Knowledge

**Audience: humans (Product Design/Management author; Claude reads).**

The canonical product understanding that feeds the pipeline — the "why" and "what"
behind any experience, independent of any UI. This is the required input before a
template is selected or configured; Claude should never invent business rules or
product context that should live here.

- [prds/](prds/) — Product Requirement Documents
- [frds/](frds/) — Functional Requirement Documents
- [personas/](personas/) — user personas referenced across products
- [business-rules/](business-rules/) — explicit, approved business rules
- [glossary/](glossary/) — shared domain/product terminology
