# DCF-0005 — Incentive Program modules

> Design Case File. Produced by FDI (FYNXT Design Inspector) per
> `[agent/fdi/README.md](../../agent/fdi/README.md)`. Reviewers: edit only **§11 Review
> Feedback** and the frontmatter `status`, then record the change in **§13 Status History**.

## 1. Summary

Four Incentive Cloud PRDs (Phases 1–4) are to be designed in the FYNXT design format and grouped under one
**Incentive Program** menu (I0). They give a broker admin: KPIs built from CRM fields as a variable or formula
(Phase 1, I1); events from the platform, the broker's websites (SDK) and CRM activities, turned into metrics, plus
custom CRM fields, both usable in the Formula Builder (Phase 2, I2/I3); rule-based enrolment (Phase 3, I4); and PAMM
rebates on Rebates programs, with an Investor Accounts fee scheme and an IB-portal view of the earnings (Phase 4,
I5/I6). **Phase 3 is already designed and built in DCF-0003 (CODE-REVIEW)**, so this case reuses it as-is and
designs only Phases 1, 2 and 4, plus the menu that joins them.

### 3.3 Business rules relied on

The design shows these rules; it does not compute them except where the PRD gives the formula for display.


| Rule | Statement                                                                                                                                                                                 | Source           |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- |
| BR1  | KPI IDs are `TKPI-n`; aggregation applies to the formula result                                                                                                                           | I1 B3, B5        |
| BR2  | Objects, fields, field types and Applicable Profiles come from the CRM                                                                                                                    | I1 B1, B2        |
| BR3  | A published metric is listed under its event's Mapped metrics and in the Formula Builder under Event metrics                                                                              | I2 B7            |
| BR4  | Number CRM fields → Calculation; Text, Date, Yes/No → Condition                                                                                                                           | I2 B8            |
| BR5  | Regenerating a site key replaces the old key; paused websites' events are not counted                                                                                                     | I2 B4, B5        |
| BR6  | Custom Events flag per tenant, set by FYNXT; off hides Websites (SDK) and + Add CRM activity as event; System events, Map to variable for System events and CRM Attributes are unaffected | I2 B10, U14      |
| BR7  | PAMM rebates ignore the program's enrollment criteria; enrolment comes only from strategy mapping                                                                                         | I5 B2            |
| BR8  | A strategy maps to only one active Rebates program; a program maps many                                                                                                                   | I5 B12           |
| BR9  | Fund Manager % + IB hierarchy % + individual % = 100 of the PF pool                                                                                                                       | I5 B9            |
| BR10 | Matrix row = referring IB's level; cells split the IB hierarchy share across that level and levels above; each row 100; applied bottom to top                                             | I5 B10, B13      |
| BR11 | Display formula: strategy PF % × IB share % = % of investor profit (e.g. 30% × 10% = 3.0%)                                                                                                | I5 U12, E7       |
| BR12 | Tier volume counts trading + PAMM lots (e.g. 2.5 + 1.5 = 4.0 / 5 lots)                                                                                                                    | I5 B5, E10       |
| BR13 | Program Settlement Period does not apply to PAMM rebates                                                                                                                                  | I5 B17           |
| BR14 | Participant Blocking overrides all eligibility criteria                                                                                                                                   | I4 B4 (DCF-0003) |
