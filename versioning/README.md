# Versioning

**Audience: humans and Claude (largely automated once tooling exists).**

The operational version records for the system's reusable artifacts. The rules that
govern this are defined in [governance/versioning-policy](../governance/versioning-policy/);
this folder holds the actual records those rules produce.

- [registry/](registry/) — machine-readable version registry (what version of what
  exists, deprecation status) for design-system and experience-library artifacts
- [changelogs/](changelogs/) — human-readable changelogs per template/pattern/design
  system release
