# Governance

**Audience: humans.** Owned by Product Design/Development leadership.

Defines how this system is allowed to operate: who decides what, how standards evolve,
and how versioning and deprecation work. Claude and contributors defer to this folder
when a process question arises (e.g. "can this experimental pattern become a standard
template?").

- [principles/](principles/) — the canonical, versioned operating principles
- [decision-log/](decision-log/) — ADR-style record of governance-level decisions
- [roles-and-responsibilities/](roles-and-responsibilities/) — who has authority over what
- [versioning-policy/](versioning-policy/) — the rules for how versioning/deprecation works
  (actual version records live in [/versioning](../versioning/))
