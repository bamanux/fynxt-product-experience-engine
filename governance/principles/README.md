# Principles

The canonical, versioned copy of the FYNXT Product Experience Engine's operating
principles (product understanding over visual design, reuse before invention, no
invented business rules or UX patterns, no automatic promotion of experiments,
designer judgement is authoritative, Figma is not the source of truth).

The root [README.md](../../README.md) mirrors these for quick reference — this folder is
the source of truth if the two ever diverge.
