# UX

**Audience: humans (Product Designers author; Claude reads/searches before proposing).**

Approved UX thinking that sits above visual design: why a flow or interaction model was
chosen, and reusable interaction patterns that haven't (yet) been promoted into a full
[experience-library](../experience-library/) template.

- [decisions/](decisions/) — UX decision records
- [patterns/](patterns/) — approved reusable UX/interaction patterns

Per the system's principles, Claude must search here before proposing a new UX pattern,
and must not invent one when an approved pattern already exists.
